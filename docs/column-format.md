# 親の学習塾 コラムのフォーマット

保護者（幼児〜小学生の親）が、スマホで、すきま時間に、安心して読めるコラムにするための決まり。
見本ページ：`site-src/column/_format-sample.html`（下書き。`npm run build:site` → 手元の `column/format-sample/` で見られる）。
見た目は `assets/column.css`。部品はすべて `.c-` で始まり、HP のほかのページには影響しない。

## 1. 使い方

- 記事ファイルの1行目の設定に `"layout":"column"` を入れる。
- 見本ページをコピーして、要らない部品を消して書く。
- `<h2>` には番号と id が自動で付き、`{{toc}}` に目次が、`{{read_time}}` に読了時間（500字＝1分）が入る。

## 2. 記事の組み立て（この順番）

| 順番 | 部品 | 決まり |
|---|---|---|
| 1 | 冒頭 `.c-hero` | カテゴリ＋タイトル＋日付・読了時間＋書いた人。**冒頭に画像は入れない**（2026-11-26 ユーザー） |
| 2 | 導入 `.c-lead` | 悩みの場面から入る。2〜3段落まで |
| 3 | まずは、わが家でチェック `.c-check` | **導入のすぐ後に置く**（2026-11-26 ユーザー）。読者が自分に当てはまるか確かめる問いを3つ＋「ひとつでも当てはまったら…」の一文 |
| 4 | この記事でわかること `.c-learn` | 3〜4個 |
| 5 | 目次 `{{toc}}` | 見出しは4〜6個 |
| 6 | 本文（h2 ごと） | **h2 ごとに、図表か吹き出しを最低1つ入れる**（文字だけの h2 を作らない） |
| 7 | まとめ `.c-summary` | 3つ |
| 8 | 参考にした研究 `.c-refs` | 研究を書いたときだけ |
| 9 | 書いた人 `.c-author` → LINE `.c-cta`（`{{line_button}}`）→ Instagram `.c-ig` | 毎回同じ。**LINE と Instagram のリンクは毎回のせる**（2026-11-26 ユーザー）。Instagram の案内（フォロワー数つき。数は scripts/build-site.mjs の IG_FOLLOWERS）はビルドで記事の最後に自動で入る（置き場所を変えたいときは本文に `{{instagram}}`） |

## 3. 部品の一覧

| 部品 | クラス | 使う場面 |

| NG→OK | `.c-ngok`（`.ng` → `.arrow` → `.ok`） | 声かけの言いかえ |
| ポイント | `.c-point` | みほ先生の大事なひと言 |
| 研究 | `.c-research` ＋ `.c-src` | 研究の紹介（下の決まりを守る） |
| ひと息 | `.c-note` | 安心のひと言、補足 |
| 実例 | `.c-voice` | 親子の実例 |
| みほ先生のひと言 | `.c-miho`（左右逆は `is-flip`） | 切り抜き写真＋みほ先生の回答の言葉をそのまま。1記事2〜3個 |
| 研究カード | `.c-study`（脳の研究は `is-brain`）＋ `.c-stats`（数字3つ）＋ 図（`.c-arrows` 原因→結果／`.c-branch` 1つ→いくつかの結果／`.c-order` 育つ順番） | **研究・脳科学の話は、必ず数字と図つきのこのカードで見せる**（2026-11-26 ユーザー：図表グラフがあったらわかりやすい） |

| くらべる | `.c-vs`（`.a` 赤み／`.b` 緑） | 2つの違い（叱る／怒る など） |
| 表 | `.c-table`（td に `data-label`） | 3列までの表。スマホでは縦に並ぶ |
| 横棒グラフ | `.c-bars`（`style="--v:48%"`） | 割合・数字（出典がある数字だけ） |
| ステップ | `.c-steps` | やることの順番 |
| ぐるぐる | `.c-cycle` | 悪循環・よい循環と、その止め方 |
| 4つの個性タイプ | `.c-types`（`t-kodawari` `t-kyokan` `t-mokuhyo` `t-jiyu`） | タイプ別の違い |
| マーカー | `.c-mark` | 1記事2〜3か所まで |

## 4. 写真とイラスト

- **イラストは使わない（2026-11-26 ユーザー：「生成したイラストは微妙すぎる。できるだけ写真を使って」）**。人物や場面の絵を SVG などで自作しない。
- **写真をそのまま貼らない（2026-11-26 ユーザー：「今の写真そのまま使いはダサい」）**。みほ先生は背景を消した切り抜き（`images/column/cut-01.png`〜`cut-07.png`）を、`.c-miho` の中で回答の言葉と一緒に使う。冒頭には画像を入れない。
  - 01 横向きでノートに赤ペン／02 本を手に笑顔／03 本棚に手をのばす（後ろ向き）／04 本を開いてほほえむ／05 ホワイトボードに書く（横向き）／06 手を差し出して笑顔／07 東大の駒場祭マグを持って笑顔
  - 正面で笑顔の 02・04・06・07 が使いやすい。同じ記事で同じ写真を使わない。
  - 新しい写真を切り抜くときは、macOS の Vision（VNGenerateForegroundInstanceMaskRequest）で背景を消し、高さ640pxの PNG にする。元の素材は「子育て相談/images/素材_みほ先生_2026-11/」。
- みほ先生の顔の丸アイコンは `images/column/miho-face.jpg`。保護者・子どもは文字の丸（`.c-ava`）。

## 5. 文章の決まり

- 1段落は2〜3行（スマホで）まで。むずかしい言葉は使わない。
- **中身の3本柱（2026-11-26 ユーザー）**：
  1. **みほ先生の回答をしっかり使う**：質問リストの回答は全部どこかに使う。大事な言葉は `.c-miho` や吹き出しで、回答の言葉のまま見せる。
  2. **脳科学・発達心理学を使う**：個別の研究の紹介だけでなく、「なぜそうなるのか」を脳のしくみ（扁桃体・前頭前野など）や発達心理学の考え方（愛着・自律性など）で説明する `.c-brain` を1記事2つ以上。みほ先生は国立大学で発達認知学・言語発達学・大脳生理学を専攻。
  3. **講座生の実例をガンガン使う**：実例は h2 を1つ立てて、お悩み → みほ先生が伝えたこと（図）→ 講座生の声（吹き出し）→ 変わったこと（くらべる図）で見せる。質問リストには毎回、講座生の実例を聞く質問を入れる。
- みほ先生の体験・考え・言葉は、**みほ先生が質問リストで答えた範囲だけ**。足した説明は、みほ先生の発言のように書かない。
- 実例は、名前・学年など個人がわかることを書かない。保護者の言葉は言いかえる。
- 研究は、実際に読んで確かめた論文・公的資料だけ。数字は出典（著者・年・雑誌）と一緒に。「〜という結果が出ています」「〜と考えられています」と、言いすぎない。一度の失敗を責めるような書き方はしない。
- グラフの数字は、出典があるものだけ。仮の数字は使わない。
- 研究・脳科学・発達心理学の話は、文章だけで終わらせず、研究カード（対象・人数・期間などの数字＋図）か、横棒グラフ・表で見せる。数字が論文の要旨などで確かめられたときは横棒グラフ（`.c-bars`）にする。確かめられない数字は書かない。数字がとりやすい公的な調査（文部科学省・内閣府・ベネッセ教育総合研究所など）も探す。
