# 親の学習塾 コラムのフォーマット

保護者（幼児〜小学生の親）が、スマホで、すきま時間に、安心して読めるコラムにするための決まり。
見本ページ：`site-src/column/_format-sample.html`（下書き。`npm run build:site` → 手元の `column/format-sample/` で見られる）。
見た目は `assets/column.css`。部品はすべて `.c-` で始まり、HP のほかのページには影響しない。

## 1. 使い方

- 記事ファイルの1行目の設定に `"layout":"column"` を入れる。
- 見本ページをコピーして、要らない部品を消して書く。
- `<h2>` には番号と id が自動で付き、`{{toc}}` に目次が、`{{read_time}}` に読了時間（500字＝1分）が入る。

## 2. 記事の組み立て（この順番）

| 順番 | 部品 | 決まり |
|---|---|---|
| 1 | 冒頭 `.c-hero` | イラスト（`images/column/` の SVG かみほ先生の写真）＋カテゴリ＋タイトル＋日付・読了時間＋書いた人 |
| 2 | 導入 `.c-lead` | 悩みの場面から入る。2〜3段落まで |
| 3 | この記事でわかること `.c-learn` | 3〜4個 |
| 4 | 目次 `{{toc}}` | 見出しは4〜6個 |
| 5 | 本文（h2 ごと） | **h2 ごとに、図表か吹き出しを最低1つ入れる**（文字だけの h2 を作らない） |
| 6 | わが家でチェック `.c-check` | 読者が今日やってみることを3つ |
| 7 | まとめ `.c-summary` | 3つ |
| 8 | 参考にした研究 `.c-refs` | 研究を書いたときだけ |
| 9 | 書いた人 `.c-author` → LINE `.c-cta` | 毎回同じ |

## 3. 部品の一覧

| 部品 | クラス | 使う場面 |
|---|---|---|
| 吹き出し | `.c-talk`（右側は `is-right`、みほ先生は `is-miho`） | 悩み（保護者）→ 答え（みほ先生）。子どもの一言も |
| NG→OK | `.c-ngok`（`.ng` → `.arrow` → `.ok`） | 声かけの言いかえ |
| ポイント | `.c-point` | みほ先生の大事なひと言 |
| 研究 | `.c-research` ＋ `.c-src` | 研究の紹介（下の決まりを守る） |
| ひと息 | `.c-note` | 安心のひと言、補足 |
| 実例 | `.c-voice` | 親子の実例 |
| 写真 | `.c-photo` | みほ先生の写真（素材はいつでも使ってよい） |
| 図のわく | `.c-fig` ＋ `.c-fig-title`（`<span>図1</span>`） | すべての図表はこの中に入れる |
| くらべる | `.c-vs`（`.a` 赤み／`.b` 緑） | 2つの違い（叱る／怒る など） |
| 表 | `.c-table`（td に `data-label`） | 3列までの表。スマホでは縦に並ぶ |
| 横棒グラフ | `.c-bars`（`style="--v:48%"`） | 割合・数字（出典がある数字だけ） |
| ステップ | `.c-steps` | やることの順番 |
| ぐるぐる | `.c-cycle` | 悪循環・よい循環と、その止め方 |
| 4つの個性タイプ | `.c-types`（`t-kodawari` `t-kyokan` `t-mokuhyo` `t-jiyu`） | タイプ別の違い |
| マーカー | `.c-mark` | 1記事2〜3か所まで |

## 4. 文章の決まり

- 1段落は2〜3行（スマホで）まで。むずかしい言葉は使わない。
- みほ先生の体験・考え・言葉は、**みほ先生が質問リストで答えた範囲だけ**。足した説明は、みほ先生の発言のように書かない。
- 実例は、名前・学年など個人がわかることを書かない。保護者の言葉は言いかえる。
- 研究は、実際に読んで確かめた論文・公的資料だけ。数字は出典（著者・年・雑誌）と一緒に。「〜という結果が出ています」「〜と考えられています」と、言いすぎない。一度の失敗を責めるような書き方はしない。
- グラフの数字は、出典があるものだけ。仮の数字は使わない。
