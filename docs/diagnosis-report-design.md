# 個別診断レポート 設計（案）

個別診断（Zoom 30分・1,000円）のあとに、結果を1枚のレポートにしてLINEで渡す。
同じテンプレートの「サンプル」を申し込み前に見せ、「このような結果が届きます」と伝える。

- 目的1：申し込み前に、1,000円で何が手に入るかを具体的に見せる（申込率を上げる）
- 目的2：受けた人に「うちの子のために分析してくれた」と感じてもらう（満足度・本講座への橋渡し）
- 約束との整合：個別診断カードの6項目（今伸びている力／強み／次に伸ばすこと／今やること・急がなくていいこと／関わり方／6〜12か月の方向性）をレポートで全部扱う

---

## 1. タイミング

| # | タイミング | 何をする | 誰が |
|---|---|---|---|
| ① | 「個別診断」と返信が来たとき | 案内文 → **サンプルレポート画像** → 申し込みカード | 自動（LINE） |
| ② | HPの個別診断ページ | 「このような結果が届きます」としてサンプルを掲載 | HP |
| ③ | 「申し込みました」の報告 → 日程確定後 | **事前アンケート（5問）** を送る。Zoomの前日までに回答 | みほ先生（LINEで送るだけ） |
| ④ | Zoom 30分 | アンケートをもとに聞き取り。レポート用のメモを取る | みほ先生 |
| ⑤ | Zoomのあと **2日以内** | 入力フォームに記入 → レポートを自動で作成 → LINEで送る | みほ先生（入力15分）＋自動 |
| ⑥ | 送付から2週間後 | 「3つのこと、試してみてどうでしたか？」と一言（本講座への自然な入口） | みほ先生 |

- ⑤の「2日以内」は、案内に書く前に運用できるか確認する。
- ⑥は自動にもできる（送信数を使う）。まずは手動でよい。

---

## 2. レポートのテンプレート

スマホで読む前提の縦長1枚（画像）。保存したい人のためにPDFも同じ内容で作る。

```
┌────────────────────────────────┐
│ わが子の強み・伸ばし方 個別診断レポート          │
│ 〇〇さん（ご家族名）／ お子さん：〇〇くん（小3）   │
│ 診断日 2026.11.20 ／ 担当 高木美保（みほ先生）     │
│ 診断No. 0012                                      │
├────────────────────────────────┤
│ ① 今回のお悩み                                    │
│ 「宿題を始めるまでに1時間かかる。声をかけると      │
│   怒って余計に始めない」                          │
│ （ご相談の言葉をそのまま）                         │
├────────────────────────────────┤
│ ② 診断結果                                        │
│ ■ お子さんのタイプ：自由型（＋こだわり型の傾向）   │
│   [4タイプのレーダー図]                            │
│ ■ 今伸びている力・強み（3つ）                     │
│   ・好きなことへの集中力 …（聞き取りの具体例）     │
│ ■ 親の関わりの傾向                                 │
│   チェックリスト 7/10 → 多かったのは「先回り」     │
│   （No.1 宿題の時間を親が決める／No.7 …）          │
│ ■ お悩みの原因の見立て                             │
│   自由型の子に「時間を決められる」ことが重なり、   │
│   始める前から気持ちが離れている …                 │
├────────────────────────────────┤
│ ③ 今日からできる3つのこと                          │
│  1. 始める時間を本人に決めさせる                    │
│     声かけ：×「宿題やったの？」→○「今日は何時から？」│
│     なぜ：自由型は「自分で決めた」ことは守りやすい   │
│  2. …                                              │
│  3. …                                              │
├────────────────────────────────┤
│ ④ まだ急がなくていいこと                           │
│   ・毎日の勉強時間を増やすこと …                    │
├────────────────────────────────┤
│ ⑤ 次に伸ばしたい力と、6〜12か月の方向性             │
│   今〜3か月：…  ／ 3〜6か月：…  ／ 6〜12か月：…     │
├────────────────────────────────┤
│ ⑥ みほ先生から                                     │
│   （手書き風の一言・2〜3行）                        │
├────────────────────────────────┤
│ 2週間後に「どうでしたか？」とLINEでお聞きします。   │
│ 困ったときは、このLINEにいつでもどうぞ。            │
└────────────────────────────────┘
```

### 「ちゃんと個別に分析している」と感じてもらう工夫

- **相手の言葉をそのまま引用する**（①のお悩み、③の場面）。テンプレートの文章ではなく「うちの話」になる。
- **データを入れる**：チェックリストの個数とチェックした項目番号、4タイプのレーダー図。数字と図があると「診断」らしくなる。
- **お子さんの呼び名・学年・具体的な場面**を随所に入れる（「〇〇くんが宿題の前にゲームを始めたとき」など）。
- **「なぜ」を必ず書く**：3つのことそれぞれに、お子さんのタイプに合わせた理由を1行。
- **やらなくていいこともはっきり言う**（④）。安心感と専門家らしさが出る。
- **診断日・診断No.・担当者名**を入れる。

## 3. 入力内容（みほ先生が記入する項目）

### 自動で入るもの（LINEのデータから）
| 項目 | 元のデータ |
|---|---|
| LINE表示名 | 友だち情報 |
| お子さんの学年区分 | 学年ボタンの回答 |
| チェックリストの個数／シートの種類 | 個数の回答 |
| 診断No. | 連番で自動 |

### 事前アンケート（Zoomの前日までに相手が回答）
1. お子さんの呼び名と学年
2. いちばん困っていること（1つ）
3. それが起きる具体的な場面（いつ・どこで・何と言ったら・どうなった）
4. お子さんが好きなこと・夢中になること
5. チェックリストで特に当てはまった項目の番号（任意）

### みほ先生がZoom後に記入
| # | 項目 | 形式 | 例 |
|---|---|---|---|
| 1 | お悩み（相手の言葉で） | 文章 1〜2文 | 宿題を始めるまでに1時間かかる… |
| 2 | 4タイプの判定 | 4つを1〜5で採点（主・副は自動） | 自由5／こだわり3／目標2／共感2 |
| 3 | 強み・伸びている力 | 3つ（各1行＋具体例） | 好きなことへの集中力：レゴを2時間… |
| 4 | 親の関わりの傾向 | 選択（先回り／管理／口出し／比較 など）＋一言 | 先回り：時間を親が決めている |
| 5 | 原因の見立て | 文章 2〜3文 | |
| 6 | 今日からできること ×3 | 各「やること」「×→○の声かけ」「なぜ」 | |
| 7 | まだ急がなくていいこと | 1〜2個 | |
| 8 | 6〜12か月の方向性 | 3段階（今〜3か月／3〜6か月／6〜12か月）各1行 | |
| 9 | みほ先生から一言 | 2〜3行 | |

- 3〜8は、よく使う文例を選べるようにしておく（タイプ別の声かけ例など）。選んでから相手に合わせて直す形にすれば、15分以内で書ける。
- 入力は、まずはGoogleフォームかスプレッドシート1行で十分。そこからレポート画像を自動で作る。

---

## 4. サンプルレポート（申し込み前に見せる用）

- 架空の家庭で1枚作る。画像の上に「サンプル（架空の例）」とはっきり入れる。実在の受講者の内容は使わない。
- 学年で2種類（未就学〜低学年／中学年以上）あると、自分ごとにしやすい。
- 見せる場所：①LINEの申し込みカードの直前、②HPの個別診断ページ。

---

## 5. 作り方（実装の目安・まだ作らない）

1. テンプレートをHTMLで作る（告知画像と同じ方法で、縦長の画像とPDFに書き出す）
2. 入力フォーム → レポート作成 → みほ先生が確認 → LINEで送る、の流れを作る
   - 送るのはみほ先生の確認後。自動では送らない。
3. サンプルレポートを作り、LINEのカード前とHPに入れる

## 決めること

- [ ] レポートは画像だけか、PDFも付けるか
- [ ] 事前アンケートを入れるか（入れると質が上がり、Zoomの時間も有効に使える）
- [ ] 入力方法（Googleフォーム／スプレッドシート／専用の入力ページ）

- [ ] 2週間後のひと声を、手動にするか自動にするか
