# 親の学習塾：HP・コラム・YouTube 集客計画

ゴールは **LINE登録（「親の習慣」チェックリストのプレゼント）に一本化**。
LINE登録後は、既存の自動導線（チェック数 → 個別分析 30分1,000円 → 美穂先生の手動フォロー）につながる。

## 1. HP を「土台」にする（最初の1か月）

### サイト構成案

```
/                 トップ（誰のための塾か・みほ先生・コラム新着・イベント・LINE登録）
/about/           みほ先生について（東大3人の子育て・指導歴30年・スクールオーク）
/program/         4ヶ月マンツーマンプログラム（今のLPをここへ）
/column/          コラム一覧
/column/<slug>/   コラム記事（1記事1テーマ）
/events/          イベント情報（無料講座・インスタライブの告知と録画リンク）
/line/            LINE登録ページ（チェックリストの紹介＋登録ボタン）。各入口からここに集める
```

### 共通ルール
- 全ページのヘッダー・記事末尾・スマホ下部固定ボタンに **「LINEでチェックリストを受け取る」**。
- 画像は埋め込まず `images/` の別ファイル（WebP・幅指定・遅延読み込み）。
- 各ページに title / description / OGP / 構造化データ（記事＝Article、著者＝Person）。
- `sitemap.xml` / `robots.txt` を置き、Search Console に登録。
- 既存の LINE 自動化（`api/`）・LP の見た目は壊さない。

### 最初にやる作業
1. 今の LP の埋め込み画像を外部ファイル化（見た目は変えない）、OGP を正しい URL に
2. `/line/` ページと、全ページ共通のヘッダー・フッター・LINEボタン
3. トップ・`/about/`・`/events/`・`/column/` の骨組み
4. コラム1本目を公開 → sitemap 送信

## 2. YouTube（撮り直さない形で始める）

| 種類 | 役割 | 素材 |
|---|---|---|
| ショート | 新しい人に見つけてもらう | インスタで再生数が多かった動画（**ロゴなしの元ファイル**） |
| ロング1本目 | チャンネルの顔。トップに固定 | 新しく撮影（10〜15分） |
| ロング2本目以降 | 中身で信頼を積む | 講座・ライブの録画をテーマごとに10〜20分に切り分け |

- 1本目の候補：「3人全員東大に進んだ子育てで、親が"やらなかったこと"」「言わなくても勉強する子に育つ、家庭の3つの習慣」
- 録画を使うとき：参加者の顔・名前・声は使わない（グループワーク・質疑は外す）。コラボ相手の録画は**相手の許可**をとる。最後の有料案内は「LINE登録」に差し替え。
- 概要欄に `/line/` へのリンク（YouTube 用の計測付き）。
- サムネイルは型を固定（悩みの言葉＋みほ先生の写真＋「東大3人の母」）。

- 事実の制約：実績・お客様の声は本当のものだけ。誇張しない。

## 6. HP の作り（2026-10-26 時点・ブランチ `feature/hp`）

- 中身は `site-src/pages/*.html`（固定ページ）と `site-src/column/*.html`（コラム）。共通のヘッダー・フッター・SEO タグは `scripts/build-site.mjs` が付ける。
- 編集したら `npm run build:site` → 生成された `index.html` 群と `sitemap.xml` をコミット。
- コラムを足す：`site-src/column/<slug>.html` を作り、1行目の設定に `path`・`title`・`description`・`date`・`category` を書く。`"draft": true` の間は検索に出ず、一覧にも出ない。
- LINE ボタンは `{{line_button}}`（入口名はページ設定の `src`）。入口ごとの計測 URL は `assets/site.js` の `LINE_URLS` に足す。
- 個別分析の「直接お支払い」は `/api/analysis/apply?src=…` → 環境変数 `PARENT_DIAGNOSIS_URL` へ転送（URL はリポジトリに書かない）。
- 本講座 LP は `/program/`（noindex、個別分析を受けた方にだけ案内）。
- 公開時：スクールオークのサイト（Netlify）の `_redirects` に `/oya/*  https://parents-school.vercel.app/:splat  200!` を追加し、school-oak-m.jp の robots.txt に `Sitemap: https://www.school-oak-m.jp/oya/sitemap.xml` を追記、Search Console に登録。
